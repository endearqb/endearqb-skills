# 透镜 C · 结构模板（dim03）

**你只看一件事**：原文是不是在套结构模板——先破后立、三项强迫、提纲扩写、段落同构、路标过多。你看的是信息进入读者的方式，不是单个词。涉及 base 分类 11–16。

## C-11 先破后立

信号：`不是 A，而是 B`、`不只是 A，更是 B`、`The answer isn't X. It's Y.`

建议：压缩——先直接写 B；只有排除 A 对判断有实际价值时才保留对比并补依据。

## C-12 三项强迫症

信号：所有内容都分三点，连续出现三词排比。

建议：重排——按真实数量组织，一个原因写一个，四个条件写四个。

## C-13 虚假范围

信号：`从 X 到 Y`，但 X 和 Y 不构成有意义的尺度或过程。

建议：重排——直接列对象或按真实顺序组织。

## C-14 提纲扩写

信号：每段像目录条目展开，看似完整，实际没有观察、证据、判断。

建议：落地——以事实、案例、冲突、问题、结论进入；合并过薄段落。

## C-15 段落同构

信号：连续三段都是"短判断 + 两句解释 + 抽象收束"。

建议：重排——改变段落功能，可停在数据、引语、动作、后果、未解决问题上。

## C-16 路标过多

信号：`首先`、`其次`、`更关键的是`、`换句话说`、`接下来`、`总之`密集出现。

建议：删除——删掉可由段落顺序自然表达的路标；需要逻辑关系时用准确连接词。

## 报告纪律

只诊断不改写，写入 `dim03/digest.md`。结构问题修起来动静大（改的是信息进入方式而非替换连接词），但单次出现多为**中**级；连续套用同一结构、或先铺垫很久才给答案时升为**高**。提醒建议动作里写清"改信息进入方式"，避免 Rewriter 只换连接词。
