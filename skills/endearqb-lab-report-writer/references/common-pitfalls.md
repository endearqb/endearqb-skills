# 常见逻辑与数据错误清单（撰写自检参考）

本文件供 Lab Report Writer 在撰写、审阅报告时对照使用。分两层：

- **A 类（机械、客观）**：能从数值表本身判定，已由 `scripts/auto_verify.py`
  的「数据规范自检」自动检查并渲染进验证面板。撰写时**核对面板提示**即可。
- **B 类（解读、主观）**：需要正文语境才能判断，脚本无法自动判定。撰写时
  逐项对照，发现疑似问题时**只在对话中向用户给出"写作自检提示"**，
  用「可能 / 建议复核」的不确定语气，**绝不擅自改写用户的数据或科学结论**
  （见 SKILL.md「数据冲突处理原则」宪法级规定）。

---

## A 类：数据与统计规范（脚本已自动检查，核对面板即可）

| 错误 | 表现 | 面板提示 |
|------|------|---------|
| 有效数字虚高 | 测量精度撑不起报告位数（千分尺读到 6 位小数） | 有效数字跨度大 ⚠ |
| 小数位不一致 | 同一物理量各点记录精度不统一 | 小数位不一致 ⚠ |
| 样本量过小 | n 很小却下普适/显著性结论 | 样本量过小/偏小 ⚠ |
| SD/SEM 混用 | 误差棒用错、均值精度与离散度混淆 | SD vs SEM ℹ |
| 异常值随意剔除 | 静默删掉"不好看"的点 | 疑似异常值 ⚠（仅标记不删） |
| 百分比不合计 | 各分项 % 之和明显 ≠100% | 百分比合计 ⚠ |

> 注：单位错误、正文/表/图三处数据是否对得上，脚本无法从数值列判定，
> 归入下方 B 类由撰写者核对。

## B 类：需正文语境判断（撰写时对照，发现问题给用户提示）

### B1 数据呈现类

1. **单位缺失 / 不一致 / 换算错误** —— 结果数值不带单位；同一量前后单位不统一；
   换算系数用错。撰写时确保每个数值都有单位且全文一致。
2. **误差不传播** —— 中间量带不确定度，最终结果却给个光秃秃的数。
   涉及多步计算时应说明不确定度如何传递。
3. **三处数据对不上** —— 同一数值在摘要、正文、表格、图中不一致。
   生成后逐一比对，数字必须完全一致。
4. **统计显著 ≠ 实际意义** —— 把 p 值小直接等同于"效应大/有意义"，
   不报告效应量或置信区间。

### B2 逻辑与论证类

5. **相关 ≠ 因果** —— 仅凭相关性直接写成因果关系。
   措辞应区分"相关/伴随"与"导致/引起"。
6. **结论超出数据支持范围** —— 把在特定条件下得到的结果过度概括，
   外推到未测量的范围/对象。
7. **缺对照、未控混淆变量** —— 没有对照组就下因果结论；未讨论可能的混淆因素。
8. **结论与数据自相矛盾 / 摘要夸大** —— 结论、摘要的口径比结果章节更强、更绝对。
9. **拿不显著的差异谈"趋势"** —— 差异在误差范围内却描述为"呈上升趋势"。
10. **误差分析空泛** —— 只写"人为误差/仪器误差"，不量化、不指向具体环节。
    应指出具体误差来源并尽量估计其量级与方向。
11. **选择性报告 / 先果后因(HARKing) / 循环论证** —— 只留支持假设的数据；
    看到结果后再补一个"刚好吻合"的假设；用结论证明前提。

## 撰写流程中的接入点

1. **生成验证面板时**：A 类已由脚本完成，确认面板里的 ⚠ 项已如实呈现。
   偏差 >5% 的，按宪法规定在「讨论」节补一句可能原因。
2. **撰写讨论/结论节时**：对照 B 类逐项自检，尤其 B5–B9。
   行文本身保持严谨（区分相关/因果、不外推、不夸大），这是**正常的写作质量**，
   不算"改用户结论"。
3. **生成报告后、`present_files` 之前**：若发现 B 类疑似问题，在对话中附一段
   **「写作自检提示」**（不写进报告正文），格式示例：

   ```
   📋 写作自检提示（供你参考，未改动报告内容）：
   - [可能] 结论第2段由单组数据推广到"所有同类材料"，建议复核 n 是否支撑此概括（对应 B6）
   - [建议] "温度升高导致活性增强"为因果表述，但实验未设对照，建议改为相关性措辞或补充说明（对应 B5/B7）
   - [提醒] 表2与图3中"转化率"数值不一致（82% vs 0.82 写法不同已统一；请确认数值本身一致）（对应 B3）
   ```

   语气一律用「可能 / 建议 / 提醒」，**列出问题供用户判断，不替用户定论，
   不擅自修改正文的数据与结论**。若无 B 类问题，可不输出此段。
